## Install

1. Download the APK from the link above on your phone.
2. If Android asks, allow this trusted browser to install it, then restore that permission afterward. Do not bypass Play Protect or security warnings.
3. Debug and release APKs use different signing identities and cannot update one another. Consider saved pairing data before uninstalling an existing app.
4. Keep PC and phone on the same Wi-Fi for future LAN pairing tests; the pairing workflow is still under development.

The public download link is NOT a private pairing QR. Never post pairing QR codes publicly. The PC handles subtitle processing; Android is the client.
